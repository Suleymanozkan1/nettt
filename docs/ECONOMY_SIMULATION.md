# Economy Simulation (Monte-Carlo)

Rules in effect: credits = ⌊score/5⌋ + 10·bosses (cap 150/show); full credits for the first 10 shows per day, then 25% ("tired audience"); ≤ 3 show-gems per day; upgrades 600/1500/3000 + 1500/4000; 11 paid cosmetics (300–6000 credits, 15–60 gems).

Generated by `packages/shared/scripts/economy-sim.ts` with the real game rules (RunSim, rewards, daily streak, missions, shop, upgrades). 120 simulated shows per skill/upgrade level feed a 60-day simulation per archetype. Players buy upgrades first, then the cheapest affordable cosmetic. No real money exists in the game.

## Reading the results

- **Progression speed**: compare "Everything owned" across archetypes — casual players should still have goals after weeks, hardcore players finish the catalogue in weeks, not days.
- **Inflation**: once everything is owned, credits only accumulate (no further sinks). The "Credits held" column at day 45–60 shows how much unspendable currency builds up; this is the signal for adding new sinks (seasonal cosmetics) before it grows large.
- Revives (gems) are not used by the bots above; real players spending gems on revives lowers gem balances further.
